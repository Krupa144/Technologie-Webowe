Web Technologies Project
Project Description
This project was created as part of the final assessment for the "Technologie Webowe" course. The goal of this project was to design and implement a simple, static website using core front-end technologies: HTML and CSS. The website demonstrates the use of basic web design principles, responsive layout, and clean code.

Features
Responsive Design: The website adjusts to different screen sizes, providing an optimal viewing experience across various devices (desktop, tablet, and mobile).
Basic HTML Structure: The project is built using valid HTML5 elements for structuring content.
CSS Styling: The website features custom CSS for styling, including layouts, colors, fonts, and basic animations.
Navigation: A simple, easy-to-use navigation menu is included for improved user experience.

Technologies Used
HTML: Used for creating the structure and content of the website.
CSS3: Used for styling and layout, including flexbox and media queries for responsiveness.
