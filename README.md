Web Technologies Project
Project Description
This project was created as part of the final assessment for the "Technologie Webowe" course. The goal of this project was to design and implement a simple, static website using core front-end technologies: HTML and CSS. The website demonstrates the use of basic web design principles, responsive layout.

Technologies Used:
HTML: Used for creating the structure and content of the website.
CSS: Used for styling and layout, including flexbox and media queries for responsiveness.
